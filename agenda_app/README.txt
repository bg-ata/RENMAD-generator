RENMAD Timed Agenda Generator
=============================

WHAT IS IT
A self-contained app to build bilingual event agendas (à la SessionLab) and
export them to Word (.doc / .docx) and PDF, with logo wall, call-to-action and
a repeating footer. No installation, no Streamlit, no server.

HOW TO OPEN
1. Keep these files together in the same folder:
      index.html   ← the app (open this)
      logos.js     ← RENMAD theme logos
      seed.js      ← the sample project that loads on first run
      agenda.ico   ← icon
2. Double-click "index.html". It opens in your web browser.
   (Chrome or Edge recommended.)
3. You need an INTERNET connection: it uses online services for the auto-
   translation and to load fonts / the Word & PDF engines.

USING IT
- "Home" lists your agendas. Open the sample, or click "+ New agenda".
- Set the event in "Event details", build each day's sessions, and set the
  bottom band in "Footer & call to action".
- Export with the top buttons:  Word (.doc)   .docx   PDF   Print.

YOUR DATA
- Projects are saved automatically IN YOUR OWN BROWSER (they do not travel with
  the file). To move a project to another computer or share it, use the ⤓
  "Download backup" button in Home, then "Import file" on the other machine.
- Up to 10 projects are kept.
